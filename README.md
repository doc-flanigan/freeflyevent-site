# freeflyevent.com

> **Star Citizen Free Fly event tracker — highest-conversion window in the portfolio**

Tracks Star Citizen Free Fly events (free trial periods). Converts players
who are trying the game for free into referral sign-ups before the event ends.

## Why This Site Matters
Free Fly events are when new player traffic spikes dramatically. A player
actively trying the game is the highest-intent audience. This site captures
them and funnels them to a referral sign-up.

## Key Feature: Event Status Banner
The EventStatusBanner component shows real-time event status (Active/Upcoming/
Inactive). Update `src/data/currentEvent.ts` when CIG announces an event.

## Funnel
freeflyevent.com → current event info → referral code → RSI signup →
o7citizen.com for new player guidance

## Tech Stack: Next.js 14 · TypeScript · Tailwind CSS · Vercel
## Setup: `npm install && npm run dev`
